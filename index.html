FaPost Core

A platform for conversational assistants and flow automation. This installs it.

$ sh -c "$(curl -fsSL https://get.fapost.in/install.sh)"

Written as sh -c "$(curl …)" rather than curl … | sh on purpose: the second form hands the script itself to standard input, leaving nothing for the questions to be answered on.

What it does

  1. Checks Docker and the Compose plugin. Nothing else is needed on the host — no PHP, no Composer, no Node.
  2. Asks for your domain and administrator email. Everything else has a default.
  3. Generates the application key and the database and Redis passwords. Written to a .env with mode 600.
  4. Starts the stack and creates the first tenant. The password goes in on standard input, so it never reaches a process list.

It writes only inside the directory it creates. No packages are installed, no services registered, nothing under /etc touched.

Requirements

Docker Engine24 or newer, with the Compose plugin v2.23+
Host4 GB RAM, 10 GB disk to start with
DNSA base domain and the tenant host beneath it, both resolving to the machine

Unattended

curl -fsSL https://get.fapost.in/install.sh -o install.sh
sh install.sh --yes \
  --domain fapost.example.com \
  --admin-email ops@example.com

Every question is also a flag. See --help for the full list, or read the script — it is one file and it is meant to be read before it is run.
